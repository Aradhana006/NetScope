# NetScope — Network & DNS Diagnostic System

NetScope is a web-based network diagnostic platform that combines DNS analysis, connectivity testing, TCP port checks, HTTP/HTTPS analysis, and network performance measurements into a unified dashboard.

## Objectives

- Analyze DNS records including A, AAAA, MX, NS, and CNAME.
- Measure network latency and packet loss.
- Check TCP port reachability.
- Verify HTTP/HTTPS availability and response times.
- Generate rule-based network health scores and diagnostic suggestions.
- Maintain analysis history and generate downloadable reports.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Visualization:** Chart.js
- **Backend:** Python, Flask
- **DNS Analysis:** dnspython
- **Connectivity:** Ping utility and Python subprocess
- **TCP Checks:** Python socket
- **HTTP/HTTPS:** Requests
- **Database:** SQLite
- **PDF Reports:** ReportLab
